Getting started

Install, add a profile, ask one question. About two minutes.

1. Install#

This downloads the binary to ~/.local/bin/jevcli (Windows: %LOCALAPPDATA%\Programs\jevcli), copies the agent skill into ~/.claude/skills, ~/.agents/skills and ~/.codex/skills (if that folder exists), and adds the Claude Code hook template, which stays disabled. JEVCLI_NO_HOOK=1 installs the skills only. Details in Install & release.

2. Point it at an endpoint#

A profile is a URL, a model name and headers. $VAR inside any of them is expanded from your environment at request time and never written to disk, so the key stays out of the config file.

The first profile you add becomes the default; jevcli profile use NAME changes it, --profile NAME overrides it for one call. A local model needs no header at all (the myjev line above).

3. Ask something#

The word is the verdict, the number is P(yes). Exit 0 means yes, 1 no, 3 unsure, 4 an error. See Ask for every form.

4. Let the agent use it#

Nothing more to do: the skill is installed and Claude Code / Codex will load it when a task matches its description (classify, triage, filter, rank, "is this X", "which of these"). The skill page shows what the agent is told.

The whole command surface#

commandwhat
askthe full command: questions inline or by name, one input or a batch
is pick filter rankshortcuts: one question, shaped for an if, a switch, a grep, a sort
questionsave, list, show, remove named questions (global or --local)
contextshow which ## Jev sections would be sent, and from which files
defaultsevery setting, its value and where it comes from; set / unset
judgefour turn-level questions: would the user accept this proposal?
pluginhook behaviours as config: list, show, add, remove, enable, disable, mode, test, log
hookthe generic runner Claude Code calls (hook run EVENT), plus status and review
profileendpoints: list, add, use, remove, show
statsthe content-free call ledger, per day and host
install uninstall--skills / --hooks (neither flag = both)
skillprint the skill Markdown
versionthe release tag (jevcli dev for a local build)
Subcommands that use Go's flag parser (ask, judge, install, uninstall, stats, plugin add, profile add) print full help on -h. The others print a one-line usage instead and exit 4; that line is what the reference pages here are checked against.
