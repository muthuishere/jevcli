Saved questions

Write a question once, tune its thresholds, and reuse it by name from any agent in any repo, or keep it with one repo.

Save one#

Then anywhere: jevcli ask urgent,team,sev < ticket.txt, jevcli is urgent < mail.txt, or jevcli ask --states tickets.jsonl team.

flagmeaning
--noul "Q"a yes/no question
--choice "Q|key=desc;key2=desc"pick one key
--score "Q|low;mid;high"one level, lowest first
--yes 0.85 --no 0.15this question's own yes/no band (yes/no only)

--context TEXT|@filebackground sent with this question only; a file is read now, at save time
--localsave into this folder's .jevcli/questions.json instead of the global config

Global or per repo#

Global questions live in ~/.config/jevcli/config.json. --local writes to the nearest .jevcli/questions.json from the working directory up (found like .git), which you can commit. A local question wins over a global one with the same name, and applies to every call made inside that folder, including an agent's. question list, show and remove take --local the same way.

For agents#

The skill tells the agent to run jevcli question list before writing a question inline, because you may already have one tuned. If a saved question's thresholds are set, they beat the config and profile values and lose only to flags on the call.

A question-set file#

ask --questions set.json takes a JSON object keyed by name: {"urgent": {"type": "noul", "instructions": "..."}, "team": {"type": "choice", "instructions": "...", "criteria": {...}}}. It is the same shape the endpoint receives, useful when a set is generated by another program.
