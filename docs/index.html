jevcli

A fuzzy if, switch and classifier for your shell and your coding agents, on any Jev-like (System One) decision model. Each call takes about 0.4 s, and batches run in parallel.

Install

# macOS / Linux
curl -fsSL https://muthuishere.github.io/jevcli/install.sh | sh

# Windows (cmd)
curl -fsSLo install.cmd https://muthuishere.github.io/jevcli/install.cmd && install.cmd

The installer puts the binary on your PATH, installs the agent skill in ~/.claude/skills and ~/.agents/skills (and ~/.codex/skills if that folder exists), and adds a Claude Code Stop-hook template that stays off until you run jevcli hook enable stop. Set JEVCLI_NO_HOOK=1 to install the skills only, or JEVCLI_VERSION=v0.1.0 to pin a version.

jevcli profile add jev https://your-endpoint/v1/systemone --model MODEL --header "Authorization: Bearer $YOUR_KEY_VAR"

If, switch, while

if jevcli feels urgent < email.txt; then claude -p "Draft a reply" < email.txt; fi

case $(jevcli match billing="about money" bug="a defect" other="anything else" < msg.txt) in
  billing) ... ;;  bug) ... ;;
esac

while ! jevcli feels "Is the build green?" --input @status.txt -q; do sleep 30; done

Many at once

jevcli query --states tickets.jsonl --parallel 8 --noul urgent="Is this urgent?" \
  | jq -c 'select(.answers.urgent.noul > .7)'
# 20 tickets: 8.2 s one at a time, 1.5 s at --parallel 8

Recipes

  • verify checks whether a source supports a claim or citation. same checks whether two records are the same entity, for deduping.
  • rank re-ranks search results. find is a semantic grep. extract pulls a date, amount, email or URL from text.
  • score rates on your own levels. tree classifies down a taxonomy. pick-func and pick-skill choose the function to call or the skill to load.
  • ask --route returns act, confirm or escalate, and --samples repeats the question to check agreement. judge checks whether you would accept an agent's turn.

The full cookbook with real outputs is at cookbook.md, or run jevcli cookbook.

Jev judges; it does not write. Pair it with any LLM for the text. It works with the hosted Jev, a self-hosted model, or your own.
